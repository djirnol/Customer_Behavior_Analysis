# Customer_Behavior_Analysis
An end-to-end analytics project analyzing retail customer purchase behavior  to identify high-value customer segments and sales trends, using SQL Server,  Python, and Power BI — simulating a real-world business analytics workflow  from raw data to an executive dashboard.

This project demonstrates an end-to-end data analytics workflow, starting from raw data loading and exploration in Python to SQL analysis and an interactive Power BI dashboard.

The project covers:

Data loading and exploration using Python
Exploratory Data Analysis (EDA)
Data cleaning and preprocessing
SQL-based data analysis using PostgreSQL / MySQL / SQL Server
Data modeling and visualization in Power BI
Dashboard and report creation
Presentation of business insights using Gamma

The objective is to transform raw data into meaningful business insights and present them through an interactive dashboard and professional report.

The dataset was initially loaded into Python using Pandas.

The raw dataset was cleaned before performing further analysis.

Cleaning activities

The cleaned data was imported into a relational database and analyzed using SQL.
